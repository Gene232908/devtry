# REPORTING.md

## CALLME

When the user sends:

```text
CALLME
```

Create a short actual weekly report using:

- `WORK_LOG.md`
- `CHANGELOG.md`
- `TASKS.md`
- `FEATURES.md`
- `KNOWN_ISSUES.md`
- `HANDOFF.md`
- Git history when available

Output:

- Reporting period.
- Overall summary.
- Daily progress for recorded days.
- Main accomplishments.
- Current status.
- Blockers.
- Next focus.
- A natural 30–60 second script for Nyash.
- Up to three possible questions and answers.

Do not invent missing days or completed work.

## DAY5REPORT

When the user sends:

```text
DAY5REPORT
```

Organize actual completed work into:

- Day 1 — Review and Planning
- Day 2 — Structure and Interface Preparation
- Day 3 — Main Implementation
- Day 4 — Debugging and Mobile Responsiveness
- Day 5 — Final Checks, Documentation, and Next Steps

Use natural, non-technical language.

Do not invent calendar dates, features, hours, tests, or results.
