# CarVibe

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a font family for Vercel.

## AI-Assisted Development

Before changing CarVibe code, AI coding agents must read and follow:

1. `AGENTS.md`
2. All mandatory files referenced by `AGENTS.md`
3. The actual affected source code and dependencies

For the complete AI development workflow, use `AI_DOCS_GUIDE.md`.

### Calling Commands

Weekly progress report:

```text
CALLME
```

Day 1 to Day 5 presentation report:

```text
DAY5REPORT
```

Full Supabase backend finalization after client approval:

```text
FINISH THE PRODUCT
```

The security, UAE privacy, DevOps, performance, debugging, and responsive-design protocols are mandatory during every implementation. They do not require a separate command.
